# AIHelper

### PCB/AOI 视觉算法开发与评测工作台

连接多模型检测、人工标注与质量评估，从整板图像追踪到具体元件，再比较不同版本的表现。

> 这是 AIHelper 的公开展示仓库。源码、模型与生产数据保留在私有环境中。

电路板自动光学检测（AOI）涉及找到元件、判断类别与方向、识别引脚和焊盘，以及读取文字。每一步的结果都会影响后续判断，模型版本变化后，还需要在多块板、多种元件上重新检查效果。

AIHelper 围绕这套工作建立了桌面调试、浏览器标注、交互式报告和批量评测工具。算法开发者可以追踪每一步的结果，测试人员可以比较版本，标注人员可以维护标准答案；这些工作通过同一批图像和结果关联起来。

## 用它可以做什么

### 运行检测，查看每个元件

从整板缩放到单个元件，查看检测框、类别、内部结构和识别文字。可以按需运行某个阶段或选定区域，也可以批量处理多个程序。

桌面还支持查看软件生成的检测框，并联动对照补框前后的变化。

### 在浏览器里完成标注

绘制和调整旋转框，标注元件、引脚、焊盘与文字。支持多选、复制粘贴、撤销和元件间切换，OCR 标注还可填写文字与阅读方向。

标注页通过本机服务保存标准答案，也可以打包成便携任务，交给另一台 Windows 电脑继续处理。

### 在图上找到问题

HTML 可视化页面可以叠加模型结果与人工标注，按漏检、误检、分类错误或框的位置偏差筛选，并直接定位到对应元件。

检测、分类和文字识别分别评价，帮助你判断问题出在“没找到”“分错类”，还是“框或文字不准确”。

### 用评分报告比较版本

将多个程序的评分汇总成 **HTML 驾驶舱和 Excel 报告**，查看不同版本、程序和元件类别的表现。

开发调试报告会列出需要优先关注的问题，展示位置、尺寸和角度误差分布，并提供返回单程序报告的链接，方便继续检查图像。

## 项目处理的关键问题

### 让多个模型围绕同一个元件协作

元件的位置、类别、朝向、内部结构和文字来自不同处理步骤。前一步调整了方向，后续裁图和识别使用的图像也可能改变。

AIHelper 串联这些步骤，保留元件与引脚、焊盘、文字之间的关系，并提供模型结果与软件生成检测框的对照。出现差异时，可以沿处理过程寻找问题开始的位置。

### 在整板大图与细小结构之间保持位置关系

同一块板可能使用不同光源、不同尺寸的图像，并经历切块、缩放和旋转裁图。局部图上的一个小偏差，映射回整板后就可能影响引脚、焊盘或文字的位置。

AIHelper 保留这些图像变换与结果位置的关系，将结果还原到整板，并支持局部高清查看。评测进一步分析中心、尺寸、角度和覆盖范围，帮助发现几何上的问题。

### 把版本变化追踪到程序、类别和具体目标

同一模型在不同程序、不同元件类别上的表现可能不同。版本评估需要同时观察整体变化和局部问题。

AIHelper 将检测、分类、内部结构和文字识别分别评价，再按程序与元件类别汇总。版本驾驶舱、误差分布和源报告链接，让读者可以从一个异常指标继续查到具体图像。

### 让人工标注与自动评测有明确依据

元件、内部结构与文字标注之间存在关联。编辑或交接标注时，需要检查这些关系是否仍然有效，也要防止旧页面覆盖新保存的内容。

AIHelper 在保存时检查关联和版本冲突，并保留备份。评分只读取人工维护的标准答案；已有结果可重新评测，历史评分可重新汇总，程序不会为了提高分数自动修改标准答案。

## 从桌面调试延伸到数据协作

这些能力也可以用于其他工作环节：

- **标注交接**：将图像、已有标注和预测结果打包，在另一台 Windows 电脑继续处理并交回成果。
- **样本准备**：批量处理普通图片并断点续跑，或按预测类别收集元件裁图，供复核与数据整理。
- **独立算法与外部调用**：在选定区域测试文字识别、连锡检测或分割，通过无界面接口向数据采集项目提供结果。

`综合评分.py` 及其 HTML／Excel 报告工具、DIP 裁图、连锡原生接入参考等分支，也纳入了[完整功能清单](docs/features.md)。
