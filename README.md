# AIHelper

### 跑模型、做标注、看报告、比较版本

面向 PCB/AOI 的视觉算法工具，让检测结果更容易查看、评估和改进。

> 这是 AIHelper 的公开展示仓库。源码、模型与生产数据保留在私有环境中。

AIHelper 用于电路板自动光学检测（AOI）的算法开发、测试和标注。你可以在桌面上运行检测，在浏览器里修改标注、检查错误，再用评分报告比较不同模型版本的表现。

## 用它可以做什么

### 运行检测，查看每个元件

从整板缩放到单个元件，查看检测框、类别、内部结构和识别文字。可以按需运行某个阶段或选定区域，也可以批量处理多个程序。

桌面还支持查看软件生成的检测框，并联动对照补框前后的变化。

### 在浏览器里完成标注

绘制和调整旋转框，标注元件、引脚、焊盘与文字。支持多选、复制粘贴、撤销和元件间切换，OCR 标注还可填写文字与阅读方向。

标注页通过本机服务保存标准答案，也可以打包成便携任务，交给另一台 Windows 电脑继续处理。

### 在图上找到问题

HTML 可视化页面可以叠加模型结果与人工标注，按漏检、误检、分类错误或框的位置偏差筛选，并直接定位到对应元件。

检测、分类和文字识别分别评价，帮助你判断问题出在“没找到”“分错类”，还是“框或文字不准确”。

### 用评分报告比较版本

将多个程序的评分汇总成 **HTML 驾驶舱和 Excel 报告**，查看不同版本、程序和元件类别的表现。

开发调试报告会列出需要优先关注的问题，展示位置、尺寸和角度误差分布，并提供返回单程序报告的链接，方便继续检查图像。

[了解综合评分与独立工具](docs/features.md#5-综合评分版本对比与开发诊断)

## 一次版本比较，可以这样做

假设换了一个模型，你想知道它在哪些地方进步、哪些地方退步：

1. **跑同一批程序**：使用相同的输入和人工标注，分别保存两个版本的结果与评分。
2. **查看版本报告**：比较检测、分类和文字识别表现，找到变化明显的程序或元件类别。
3. **定位具体目标**：从汇总页进入单程序报告，在图上查看漏检、错分或框的位置偏差。
4. **带着样本继续调试**：结合图像、标注与模型结果，确定下一步排查方向。

已有结果也可以直接评测，汇总报告无需重新运行模型。评分读取人工标注，不会为了提高分数自动修改标准答案。

## 还有这些实用工具

- **标注任务交接**：打包图像、已有标注和预测结果，在其他电脑继续标注并交回成果。
- **样本收集与批处理**：普通图片可批量处理并断点续跑；元件裁图可按预测类别整理。
- **局部算法测试**：在选定区域运行文字识别、连锡检测或分割。
- **对接其他项目**：通过无界面调用接口提供检测结果，供数据采集等流程使用。

包括 `综合评分.py`、DIP 裁图和连锡接入参考在内的独立工具，都收录在[完整功能清单](docs/features.md)中。
